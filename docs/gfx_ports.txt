AVDC COMMANDS
-------------

Bit columns: D7 D6 D5 D4 D3 D2 D1 D0

Legend:
- V = 4-bit value field (used in D3..D0), V = 0 to 14
- N = mask/select bit (meaning depends on command)
- d = “don’t care” / ignored by decoder
- 0¹ / 1² = bit value shown in the original table with footnote markers (definitions not included in the snippet)

INSTANTANEOUS COMMANDS

1) Master reset
   D7..D0 = 0 0 0 0 0 0 0 0

2) Load IR pointer with value V (V = 0..14)
   D7..D0 = 0 0 0 1 V V V V

3) Disable graphics
   D7..D0 = 0 0 1 d d d 1 0¹

4) Enable graphics
   D7..D0 = 0 0 1 d d d 1 1²

5) Display off; float DADD bus if N = 1
   D7..D0 = 0 0 1 d 1 N d 0¹

6) Display on; select update timing:
      - Next field if N = 1
      - Scan line if N = 0
   D7..D0 = 0 0 1 d 1 N d 1²

7) Cursor off
   D7..D0 = 0 0 1 1 d d d 0¹

8) Cursor on
   D7..D0 = 0 0 1 1 d d d 1²

9) Reset interrupt/status bits (bit reset wherever N = 1)
   D7..D0 = 0 1 0 N N N N N

10) Disable interrupts (disable wherever N = 1)
    D7..D0 = 1 0 0 N N N N N

11) Enable interrupts (enable wherever N = 1)
    D7..D0 = 0 1 1 N N N N N


INTERRUPT BIT ASSIGNMENTS (for the five N bits, left→right)
Assuming N bits correspond to D4..D0 in order:
- D4: VB
- D3: LZ
- D2: SP1
- D1: RDY
- D0: SP2


DELAYED COMMANDS (with Hex opcode shown)

A4  (1 0 1 0 0 1 0 0)  Read at pointer address
A2  (1 0 1 0 0 0 1 0)  Write at pointer address
A9  (1 0 1 0 1 0 0 1)  Increment cursor address
AC  (1 0 1 0 1 1 0 0)  Read at cursor address
AA  (1 0 1 0 1 0 1 0)  Write at cursor address
AD  (1 0 1 0 1 1 0 1)  Read at cursor address and increment address
AB  (1 0 1 0 1 0 1 1)  Write at cursor address and increment address
BB  (1 0 1 1 1 0 1 1)  Write from cursor address to pointer address
BD  (1 0 1 1 1 1 0 1)  Read from cursor address to pointer address
